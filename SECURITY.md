# Security policy

Do not open a public issue containing credentials, enrollment keys, registry
tokens, operator passwords, private keys, production configuration, customer
data, or sensitive logs.

Report suspected vulnerabilities with GitHub's private **Report a
vulnerability** form on this repository's Security tab:

<https://github.com/GreenerSolutions/greener-installer/security/advisories/new>

Include the affected release tag and asset checksum, but redact all secrets and
site-specific data.

Only release assets downloaded from this repository's GitHub Releases page and
verified against their published checksum are supported. Release assets are
append-only: fixes are published under a new tag rather than replacing an
existing asset.
